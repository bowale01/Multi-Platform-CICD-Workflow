## Network Flow

```
┌────────────────────────────────────────────────────────────────┐
│ 1. User visits https://adelekeadebowale.com                   │
└──────────────────────────┬─────────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────────┐
│ 2. DNS resolves to EC2 Public IP                              │
└──────────────────────────┬─────────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────────┐
│ 3. Request hits EC2 instance on port 443 (HTTPS)             │
└──────────────────────────┬─────────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────────┐
│ 4. NGINX receives request                                     │
│    - Checks server_name match                                 │
│    - Applies SSL certificate                                  │
└──────────────────────────┬─────────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────────┐
│ 5. NGINX routes to appropriate backend                        │
│    - adelekeadebowale.com → localhost:3000                    │
│    - staging. → localhost:3001                                │
│    - dev. → localhost:3002                                    │
└──────────────────────────┬─────────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────────┐
│ 6. Docker container processes request                         │
│    - Container serves application                             │
│    - Returns response                                         │
└──────────────────────────┬─────────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────────┐
│ 7. NGINX returns response to user over HTTPS                  │
└────────────────────────────────────────────────────────────────┘
```

## CI/CD Pipeline Flow

```
┌──────────────────────────────────────────────────────────────┐
│ Developer commits to branch (develop/staging/main)           │
└──────────────┬───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│ GitHub Actions detects push event                            │
│ - Determines which workflow to trigger based on branch       │
└──────────────┬───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│ Workflow executes                                            │
│ 1. Checkout code                                             │
│ 2. Configure AWS credentials                                 │
│ 3. Login to ECR                                              │
└──────────────┬───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│ Build Docker image                                            │
│ - Platform: linux/amd64                                      │
│ - Tag: latest/staging/dev based on branch                   │
└──────────────┬───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│ Push image to AWS ECR                                         │
│ - Uploads to specific tag                                    │
│ - Overwrites previous version                                │
└──────────────┬───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│ SSH into EC2 instance                                         │
│ - Uses stored private key from GitHub Secrets               │
│ - Authenticates as ubuntu user                               │
└──────────────┬───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│ Deploy on EC2                                                 │
│ 1. Login to ECR from EC2                                     │
│ 2. Pull latest image with correct tag                       │
│ 3. Stop existing container (if running)                     │
│ 4. Remove old container                                      │
│ 5. Start new container on correct port                      │
│ 6. Clean up unused images                                   │
└──────────────┬───────────────────────────────────────────────┘
               │
               ▼
┌──────────────────────────────────────────────────────────────┐
│ Application live!                                             │
│ - Container running                                          │
│ - NGINX routing traffic                                      │
│ - HTTPS enabled                                              │
└──────────────────────────────────────────────────────────────┘
```

## Security Layers

```
┌────────────────────────────────────────────────────────────────┐
│ Layer 1: GitHub                                                │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ - GitHub Secrets for sensitive data                       │ │
│ │ - Encrypted in transit and at rest                        │ │
│ │ - Only accessible by GitHub Actions                       │ │
│ └────────────────────────────────────────────────────────────┘ │
└──────────────────────────┬─────────────────────────────────────┘
                           │
┌────────────────────────────────────────────────────────────────┐
│ Layer 2: AWS IAM                                               │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ - Least privilege access                                   │ │
│ │ - Scoped to ECR push/pull only                            │ │
│ │ - Key rotation recommended                                 │ │
│ └────────────────────────────────────────────────────────────┘ │
└──────────────────────────┬─────────────────────────────────────┘
                           │
┌────────────────────────────────────────────────────────────────┐
│ Layer 3: AWS Security Groups                                   │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ - Port 22: SSH (restricted to necessary IPs)             │ │
│ │ - Port 80: HTTP (redirects to HTTPS)                     │ │
│ │ - Port 443: HTTPS (public access)                        │ │
│ │ - All other ports: Blocked                                │ │
│ └────────────────────────────────────────────────────────────┘ │
└──────────────────────────┬─────────────────────────────────────┘
                           │
┌────────────────────────────────────────────────────────────────┐
│ Layer 4: UFW Firewall (on EC2)                                │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ - OpenSSH allowed                                          │ │
│ │ - Nginx Full allowed (80, 443)                            │ │
│ │ - Default deny incoming                                    │ │
│ └────────────────────────────────────────────────────────────┘ │
└──────────────────────────┬─────────────────────────────────────┘
                           │
┌────────────────────────────────────────────────────────────────┐
│ Layer 5: SSL/TLS                                               │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ - Let's Encrypt certificates                               │ │
│ │ - Automatic renewal every 60 days                         │ │
│ │ - TLS 1.2+ only                                           │ │
│ │ - Strong cipher suites                                     │ │
│ └────────────────────────────────────────────────────────────┘ │
└──────────────────────────┬─────────────────────────────────────┘
                           │
┌────────────────────────────────────────────────────────────────┐
│ Layer 6: NGINX                                                 │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ - Security headers (X-Frame-Options, CSP, etc.)           │ │
│ │ - HTTP to HTTPS redirect                                   │ │
│ │ - Request rate limiting (optional)                         │ │
│ └────────────────────────────────────────────────────────────┘ │
└──────────────────────────┬─────────────────────────────────────┘
                           │
┌────────────────────────────────────────────────────────────────┐
│ Layer 7: Docker Container Isolation                            │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ - Isolated file system                                     │ │
│ │ - Resource limits                                          │ │
│ │ - Network isolation between containers                     │ │
│ │ - Read-only root filesystem (optional)                    │ │
│ └────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

## Environment Promotion Flow

```
Feature Development → Development → Staging → Production

┌──────────────┐
│  Developer   │
│    works     │
│  on feature  │
└──────┬───────┘
       │ git checkout -b feature/name
       │ (work on feature)
       │
       ▼
┌──────────────┐
│   Feature    │
│   Branch     │
└──────┬───────┘
       │ Pull Request
       │ Code Review
       │
       ▼
┌──────────────┐     Auto Deploy
│   Develop    ├──────────────────► dev.adelekeadebowale.com
│   Branch     │                    (Port 3002, :dev tag)
└──────┬───────┘
       │ Test & Validate
       │ git merge develop
       │
       ▼
┌──────────────┐     Auto Deploy
│   Staging    ├──────────────────► staging.adelekeadebowale.com
│   Branch     │                    (Port 3001, :staging tag)
└──────┬───────┘
       │ Final QA
       │ git merge staging
       │
       ▼
┌──────────────┐     Auto Deploy
│     Main     ├──────────────────► adelekeadebowale.com
│   Branch     │                    (Port 3000, :latest tag)
└──────────────┘
   (Production)
```
